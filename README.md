# Timer App

A simple timer application built with React and TypeScript.

## About the Project
This project was created to practice building a frontend application with TypeScript and React.
The application allows users to interact with a timer through a simple and responsive interface.

### Technologies

* React
* TypeScript
* HTML
* CSS
* Git & GitHub

### Features

* Start and control the timer
* Interactive user interface
* Responsive layout
* TypeScript-based React components
